# 怪物 LLM 提取 Schema（5e_chm md → 5etools 兼容 JSON）

本契约是 LLM 子代理（flash 模型）从 `5e_chm/md/` 的 markdown 怪物页提取
5etools 兼容 `bestiary-*.json` 的唯一权威规范。产物被 `build_kb.py` 的
`_monster_body` / `_monster_tags` 原样消费，字段必须严格对齐。

5e_chm 的怪物页分**三大格式族**，识别方式与提取规则各不相同，见 §2–§4。
输出 JSON 格式**统一**（见 §5），与格式族无关。

---

## §1 总则（所有格式族通用）

1. **只提取含统计块的页面**。判别：出现 CR 行（`挑战等级`/`CR`）或
   `护甲等级`/`AC` + `生命值`/`HP` 之一。纯 lore 页（只有背景故事/外观/
   栖息地描写）、章节页（「第七章：神话生物」「龙类」「色彩龙」）、
   群组总览页（「深潜者总」「幽影龙总」）、巢穴动作页（`#### 巢穴动作` /
   `#### 区域效应` 且无统计块）、占位空壳（`New_Item.md`）一律**跳过**。
2. **一个文件可能含多个怪物**（2014 龙类 1 文件含 4 年龄、部分 MTG 书 1 文件
   含多城邦变体）。每个统计块产**一条** JSON 条目，不得合并或遗漏。
3. **name / ENG_name**：标题「`红龙雏龙Red Dragon Wyrmling`」→
   `name="红龙雏龙"`、`ENG_name="Red Dragon Wyrmling"`。中文名与英文名之间
   无空格也照拆（拆在第一个英文字母处）。
4. **清理 md 瑕疵**：
   - `*斜体*` → 去掉 `*`；
   - 标题英文后粘连的重复句号（`水陆两栖Amphibious.。`）→ 去掉；
   - 正文里夹带的英文原文段（MTG 书常见，中文段后紧跟一段英文）→ **丢弃英文段**；
   - 「（详见XXX）」等源内引用说明 → 保留原样。
5. **缺失字段**：不适用/未出现的字段省略或空数组，**不要编造**。没有
   「抗性/易伤」就不写该字段。

## §2 格式族 A：2024/2025 表格格式

代表书：怪物图鉴2025、被遗忘的国度、鸦阁魔域：魔障深藏、艾伯伦：奇械锻炉、
多数第三方书。

结构特征：`##### 名字English`（H5）开头的统计块；AC/HP/速度/技能/免疫/感官/
语言/CR 用 **markdown 管道表**；六维属性用**原始 HTML `<table>`**；
`###### 特质Traits` / `###### 动作Actions` / `###### 反应Reactions` /
`###### 传奇动作Legendary Actions`（H6）分区。

提取规则：
- **类型行**：`##### 名` 下一行「`巨型龙类（金属龙），守序善良`」→
  体型+类型（+括号标签）+阵营（见 §6 词表）。
- **AC/HP/速度管道表**：`AC 13` → `ac=13`；`HP 45（10d6+10）` →
  `hp={"average":45,"formula":"10d6+10"}`；`速度 30尺` →
  `speed={"walk":30}`，`速度 40尺，飞行80尺，游泳40尺` →
  `speed={"walk":40,"fly":80,"swim":40}`。
- **先攻行**（`先攻 +3（13）`）→ **跳过**，不产出字段。
- **属性 HTML table**：六列（力量/敏捷/体质/智力/感知/魅力），每项取**第 4 列
  数值**（如 `力量 8` → `str=8`）。「调整」「豁免」列不产出。
- **技能/免疫/感官/语言/CR 管道表**：与试点规则一致。`免疫 火焰` →
  `immune=["火焰"]`；`免疫 火焰；魅惑，恐慌` → 分号前 `immune=["火焰"]`、
  分号后 `conditionImmune=["魅惑","恐慌"]`（全伤害/全状态则另一组缺省）。
  `CR 17（XP18,000，或巢穴内20,000；PB+6）` → `cr="17"`（巢穴 XP 丢弃）。
- **特性/动作块**：`水陆两栖Amphibious。金龙可以在空气和水中呼吸。` →
  `{"name":"水陆两栖","entries":["金龙可以在空气和水中呼吸。"]}`。
  攻击：`撕裂Rend。*近战攻击检定：*+14，触及10尺。*命中：*17（2d8+8）挥砍伤害外加4（1d8）火焰伤害。`
  → 去 `*` 后正文原样入 entries（`近战攻击检定：+14，触及10尺。命中：17（2d8+8）挥砍伤害外加4（1d8）火焰伤害。`）。
- **充能**：`火焰吐息Fire Breath（充能5~6）` → name 保留中文+括号
  `"火焰吐息（充能5~6）"`。
- **施法**：`施法Spellcasting。金龙施展以下一道法术，无需材料成分并使用魅力作为施法属性（法术豁免DC21，法术攻击命中+13）：*随意：侦测魔法Detect Magic，光导箭Guiding Bolt*（二环版本）...*每项1/日：焰击术Flame Strike...*`
  → `spellcasting=[{"name":"施法","ability":"cha","headerEntries":["金龙施展以下一道法术…（法术豁免DC21，法术攻击命中+13）："],"will":["侦测魔法","光导箭（二环版本）"],"daily":{"1":["焰击术","诚实之域"]}}]`。
- **传奇动作**：`###### 传奇动作Legendary Actions` 下第一段
  「传奇动作次数：3（巢穴内4）。…」入 `legendary` 的首条 entries（或保留为
  `legendary` 列表前导说明），随后每个动作为一项。

## §3 格式族 B：2014 文本格式

代表书：怪物图鉴（2014）、多元宇宙的怪物、瓦罗怪物指南、魔邓肯的众敌卷册、
模组（36 个冒险）、巨人之荣耀、费资本的巨龙宝库等。

结构特征：怪物名是**普通文本行**（非标题），后接 `*体型类型，阵营*` 斜体行，
再是**空行分隔的 key-value 行**；六维分两行（每行 3 属性）；特性是
`*名。*正文` 斜体段；`动作` / `传奇动作` 是普通文本段标题；
龙类一文件含 4 个年龄统计块（雏龙/青年/成年/远古）。

提取规则：
- **类型行**：`*巨型亡灵，普遍混乱邪恶*` → 体型=巨型、类型=亡灵（→undead）、
  阵营=混乱邪恶（→`["C","E"]`）。**「普遍」前缀丢弃**（表示 typically）。
- **AC/HP/速度/属性等 key-value 行**（空行分隔）：
  `护甲等级：14` → `ac=14`；`护甲等级：17（天生护甲）` → `ac=17`（括号护甲说明丢弃）；
  `生命值：337（25d12+175）` → `hp={"average":337,"formula":"25d12+175"}`；
  `速度：40尺，飞行40尺` → `speed={"walk":40,"fly":40}`；
  `力量22（+6） 敏捷19（+4） 体质24（+7）`（第一行）→ str=22/dex=19/con=24；
  `智力6（-2） 感知9（-1） 魅力8（-1）`（第二行）→ int=6/wis=9/cha=8。
  **属性值取括号外数字**（如 `力量22` → 22，`（+6）` 是调整值丢弃）。
- **豁免/技能**：`豁免：体质+13` → `save={"con":"+13"}`；
  `技能：察觉+4*` → `skill={"perception":"+4"}`（**去掉尾随 `*`**，那是
  熟练标记脚注）。
- **伤害抗性/免疫/易伤**：`伤害抗性：强酸，寒冷，火焰，闪电，雷鸣；非魔法攻击的钝击、挥砍、穿刺伤害`
  → 分号前普通类型 + 分号后**条件抗性**：`resist=["强酸","寒冷","火焰","闪电","雷鸣",
  {"resist":["钝击","挥砍","穿刺"],"note":"非魔法攻击"}]`。
  `伤害免疫：暗蚀，毒素` → `immune=["暗蚀","毒素"]`。
  `状态免疫：力竭，恐慌，受擒，麻痹，石化，中毒，倒地，束缚` →
  `conditionImmune=["力竭","恐慌","受擒","麻痹","石化","中毒","倒地","束缚"]`。
- **感官**：`感官：黑暗视觉120尺，被动察觉9` → `senses=["黑暗视觉120尺"]`、
  `passive=9`。
- **语言**：`语言：——` 或 `语言：—` → 无语言（`languages=[]` 或缺省）。
- **CR**：`挑战等级：20（25,000xp）熟练加值 +6` → `cr="20"`；
  `挑战等级：1/2（100xp）` → `cr="1/2"`（保留分数）。XP/熟练加值丢弃。
- **特性**：`湮灭灵光Annihilating Aura。所有在…` → 斜体 `*名。*` 里的中文名
  为 name（去掉英文与重复标点），`。` 后正文入 entries。
- **动作段**：`动作`（独立文本行）之后每段 `*名。*正文` 为一项 action。
  `*啃咬Bite。近战武器攻击：*命中+6，触及5尺，单一目标。*命中：*9（1d10+4）点穿刺伤害…`
  → name="啃咬"，entries 去 `*` 后正文。
- **传奇动作段**：`传奇动作` 文本行后，先一段「红龙拥有3传奇动作…」说明入
  `legendary` 首条，随后 `侦查Detect。红龙进行一次感知（察觉）检定。` 每项一条。
- **龙类多块**：`红龙雏龙Red Dragon Wyrmling` / `青年红龙Young Red Dragon` /
  `成年红龙Adult Red Dragon` / `远古红龙Ancient Red Dragon` 各产一条独立条目；
  `#### 巢穴动作` / `#### 区域效应` 段落**跳过**。
- **施法**（怪物式 `will`/`daily`）：`*随意：魅惑类人，易容术…1/日：雷鸣波*` 规则同试点 §1。

## §4 格式族 C：MTG 变体

代表书：塞洛斯之神话奥德赛、拉尼卡公会长指南、斯翠海文：混沌研习。

结构特征：标签**缩写**（`AC：` / `HP：`）且**冒号前常有空格**，同书内也可能混用
中文标签（`护甲等级 ：14`）；六维**单行**；`————————————————` 全角破折号作分隔；
夹带英文原文段；`无阵营` 粘连在类型后；一文件可能含多城邦变体（如「重装步兵」含
阿喀洛斯/迈勒提斯/瑟特萨三种）。

提取规则：
- **标签归一**：`AC：` / `护甲等级 ：` → ac；`HP：` / `生命值 ：` → hp；
  `速度：` → speed；`挑战等级：` → cr。冒号前空格、`：`/`:` 混用都接受。
- **类型行**：`中型怪兽无阵营` → 体型=中型、类型=怪兽（→monstrosity）、
  阵营=无阵营（→`["U"]`）；`中型类人（任意种族），任意阵营` →
  类型=humanoid、标签=[任意种族]、阵营=`["A"]`。
- **六维单行**：`力量14（+2） 敏捷18（+4） 体质12（+1） 智力3（-4） 感知10（+0） 魅力3（-4）`
  → 六个属性一次性取括号外数字。
- **分隔线**：`————————————————` / `________________________________________`
  全角破折号或下划线，仅作视觉分隔，**忽略**。
- **特性/动作**：`双头Two Head.双头蛇在…`（英文名后**半角点 `.`**）→
  name 取中文「双头」，entries 取 `.` 后正文。攻击 `啃咬Bite.近战武器攻击：+6命中，触及5尺，单一目标命中：6（1d4+4）穿刺伤害…`
  → 去英文、正文原样（注意 MTG 用 `+6命中` 而非 `命中+6`，保持原样即可）。
- **施法（法术位式）**：`施法Spellcasting.重装步兵是一位3级施法者…戏法（任意）：*法师之手…*1环（4法术位）：*七彩喷射…*2环（2法术位）：*朦胧术…*`
  → `spellcasting=[{"name":"施法","ability":"int","headerEntries":["重装步兵是一位3级施法者，其施法属性为智力（法术豁免DC13，法术攻击命中+5）。它学习并准备了如下法师法术："],"spells":{"0":{"spells":["法师之手","次级幻象","冷冻射线"]},"1":{"spells":["七彩喷射","脚底抹油","睡眠术"],"slots":4},"2":{"spells":["朦胧术","匕首之云","隐形术"],"slots":2}}}]`。
- **多城邦变体**：每个变体统计块产独立条目（如 阿喀洛斯重装步兵/迈勒提斯重装步兵/瑟特萨重装步兵）；每个变体后的「队名表」（`d8 Name` 表）**跳过**。
- **英文段**：中文正文后紧跟的英文原文段 **丢弃**。

## §5 输出 JSON Schema（统一，monster 数组元素）

```json
{
  "name": "深潜者",
  "ENG_name": "Deep One",
  "source": "火炬光下的克苏鲁",
  "edition": "2024",
  "translator": "不全书",
  "size": "M",
  "type": {"type": "aberration", "tags": ["神话生物"]},
  "alignment": ["L", "E"],
  "ac": 14,
  "hp": {"average": 44, "formula": "8d8+8"},
  "speed": {"walk": 30, "swim": 30},
  "str": 16, "dex": 10, "con": 12, "int": 15, "wis": 11, "cha": 13,
  "save": {"str": "+5", "int": "+4"},
  "skill": {"athletics": "+5", "perception": "+2"},
  "immune": ["毒素"],
  "resist": ["火焰", {"resist": ["钝击", "穿刺", "挥砍"], "note": "非魔法攻击"}],
  "vulnerable": [],
  "conditionImmune": ["中毒"],
  "senses": ["黑暗视觉60尺"],
  "passive": 12,
  "languages": ["通用语"],
  "cr": "2",
  "spellcasting": [{"name": "施法", "ability": "int", "will": ["魅惑类人"], "daily": {"1": ["雷鸣波"]}}],
  "trait": [{"name": "水陆两栖", "entries": ["深潜者可以在空气和水中呼吸。"]}],
  "action": [{"name": "多重攻击", "entries": ["深潜者发动两次爪击和一次啃咬攻击。"]}],
  "bonus": [], "reaction": [], "legendary": [], "mythic": [],
  "environment": []
}
```

字段要点：
- `size`：`"T"|"S"|"M"|"L"|"H"|"G"`（可数组，如双体型 `["M"]`）。
- `type`：dict `{"type":英文码,"tags":[...]}` 或纯英文码字符串。
- `alignment`：轴码数组（见 §6 阵营表）。
- `ac`：整数（护甲说明丢弃）。
- `hp`：`{"average":int,"formula":str}`。
- `speed`：dict，键 walk/climb/swim/fly/burrow，值 int；悬浮/条件速度可
  `{"number":30,"condition":"(悬浮)"}`。
- `save`/`skill`：dict，键为英文码，值字符串如 `"+5"`。
- `immune`/`resist`/`vulnerable`：字符串列表，元素可为字符串或条件 dict
  `{"resist":[...],"note":"非魔法攻击"}`（`immune`/`vulnerable` 同理换键）。
- `conditionImmune`：字符串列表（**只取状态名**，去掉括号注释，如
  「魅惑（对其吸血鬼尊长无效）」→「魅惑」）。
- `cr`：字符串，`"0"|"1/8"|"1/4"|"1/2"|"2"|"30"`…（分数保留）。
- `spellcasting`：数组，元素含 `name`/`ability`/`headerEntries`/`will`/`daily`
  或 `spells`（法术位式，键 "0"=戏法，其余环阶带 `slots`）。
- `trait`/`action`/`bonus`/`reaction`/`legendary`/`mythic`：数组，元素
  `{"name":中文名,"entries":[正文段落]}`。正文保留中文原样（去 `*` 与英文段）。

## §6 词表

### 体型
微型=T、小型=S、中型=M、大型=L、巨型=H、超巨型=G。

### 类型（含常见变体 → 英文码）
异怪=aberration、野兽=beast、天界生物/天族=celestial、构造体/构装=construct、
龙类/龙=dragon、元素=elemental、精类/妖精=fey、邪魔=fiend、巨人=giant、
类人生物/类人=humanoid、怪物/怪兽=monstrosity、泥怪=ooze、植物=plant、
不死生物/亡灵=undead、虫群=swarm。
括号标签（如「（金属龙）」「（任意种族）」「（神话生物）」）→ `type.tags`。

### 阵营（轴码数组，格式族内中文 → 码）
守序善良=`["L","G"]`、中立善良=`["N","G"]`、混乱善良=`["C","G"]`、
守序中立=`["L","N"]`、绝对中立/中立=`["N"]`、混乱中立=`["C","N"]`、
守序邪恶=`["L","E"]`、中立邪恶=`["N","E"]`、混乱邪恶=`["C","E"]`、
无阵营=`["U"]`、任意阵营=`["A"]`、任意邪恶=`["L","N","C","E"]`、
任意善良=`["L","N","C","G"]`。前缀「普遍」（typically）丢弃。

### 属性（豁免键 / 中文 → 英文码）
力量=str、敏捷=dex、体质=con、智力=int、感知=wis、魅力=cha。

### 技能（中文 → 英文码）
特技=acrobatics、驯兽=animalHandling、奥秘=arcana、运动=athletics、欺瞒=deception、
历史=history、洞悉/观察=insight、威吓=intimidation、调查=investigation、医药=medicine、
自然=nature、察觉=perception、表演=performance、游说=persuasion、宗教=religion、
巧手=sleightOfHand、隐匿=stealth、生存/求生=survival。

### 伤害类型（canonical 中文，见 kb_enums.DAMAGE_TYPE_CN）
强酸、钝击、寒冷、火焰、力场、闪电、暗蚀、穿刺、毒素、心灵、光耀、挥砍、雷鸣。
变体收敛：酸→强酸、火→火焰、黯蚀/坏死→暗蚀、雷/音波→雷鸣。
特殊抗性/免疫（非伤害类型，如「法术伤害」「非魔法攻击的伤害」）用
`{"special":"法术伤害"}` 表示。

### 状态（canonical 中文，见 kb_enums.CONDITION_CN）
目盲、魅惑、耳聋、力竭、恐慌、受擒、失能、隐形、麻痹、石化、中毒、倒地、束缚、
震慑、昏迷、疾病。变体收敛：擒抱→受擒、恐惧→恐慌、受控→魅惑、定身→束缚。

### 感官前缀（保留数值原样）
黑暗视觉、盲视、真实视觉、震颤感知（颤动感知→震颤感知）。

## §7 输出要求

- 每本书输出一个 JSON 文件，顶层 `{"monster": [ ... ]}`。
- 文件名 `bestiary-<code>.json`（code 由批次指令给定，如 `xmm`/`mm`/`mot`，
  第三方书用拼音/英文短名）。
- 严格 JSON，无注释、无 markdown 代码围栏之外的文字。
- `source`/`edition`/`translator` 由批次指令给定：官方书 `source=<码>`、
  `edition=<2014|2024>`；第三方书 `source=<中文书名>`。`translator` 一律 `"不全书"`。
