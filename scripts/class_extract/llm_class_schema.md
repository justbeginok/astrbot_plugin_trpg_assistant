# LLM 职业提取契约（class_extract LLM 兜底，参照 llm_monster_schema.md 模式）

## 输入
给定一个 5e_chm 职业/子职 md 文件全文（人工校对中文，可能含表格/列表/怪物统计块混排）。

## 输出
输出一个 JSON 对象（仅 JSON，无其他文字），结构：

```json
{
  "className": "德鲁伊",
  "subclass": "落英结社",              // 子职文件必填；职业主体留空
  "classFeature": [],                  // 职业主体特性（subclass 文件留空数组）
  "subclassFeature": [
    {
      "name": "落英之护",
      "level": 3,
      "source": "LOO",
      "entries": ["从3级起，你获得……"]
    }
  ]
}
```

## 规则
1. **level 必填**：从正文推断（「第X级/自X级/X级时/在你X级选择」），范围 1-20。
   同一特性在多个等级获得（如「属性值提升」）→ 只输出一行，level=首次获得等级。
2. **name**：特性名取中文名（去掉英文原名），不含「特性」「选项」等冗余后缀。
3. **entries**：数组，单元素 = 该特性完整正文（纯文本，合并段落；丢弃
   表头/图片/翻译署名行）。
4. 丢弃：非特性内容（简介段落、创建角色指南、职业表、生命值/熟练项/装备段、
   法术表、怪物统计块——若该文件混入怪物数据则只保留职业/子职特性）。
5. 子职文件 className=所属职业中文名（德鲁伊/游侠…）；source 由调用方注入，
   输出中可省略 source（合并时补）。
6. 无法判断的段落不要编造；拿不准的等级宁缺毋滥（可省略该特性）。
