# astrbot_plugin_trpg_assistant

**当前版本：v0.54.1**（各功能版本演进详见 [CHANGELOG.md](CHANGELOG.md)）

适用于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的 TRPG 跑团助手插件：完整 Roll20 规范的 D&D 骰池投掷、技能检定、投掷历史、战斗先攻追踪、个人/队伍背包、会话商店、角色卡与 LLM 引导车卡、内置 DND 5e 中文知识库，并提供 LLM 函数工具供 AI 主持人在叙事中自动调用。

## 功能一览

| 功能           | 说明                                                   |
| ------------ | ---------------------------------------------------- |
| **掷骰**       | Roll20 完整语法：保留/丢弃、优势劣势、爆炸骰、重骰、成败计数、DC 检定、天然 20/1     |
| **先攻追踪**     | `/ri` 掷先攻入列、`/init` 查看/推进回合，自动轮数计数                   |
| **背包管理**     | 个人背包 + 队伍背包，物品带重量/价值/备注，支持流转与总量统计                    |
| **商店系统**     | 会话商店：DM 配置商品，玩家自助买卖，自动扣款找零（货币即物品）                    |
| **角色卡**      | 多卡管理，`/r 察觉` 自动按活跃卡加修正，技能专精/万事通/武器熟练自动生效             |
| **LLM 引导车卡** | 按 DnD 规则逐步引导建卡（2014/2024 双路径），属性生成与校验由插件确定性执行        |
| **知识库查询**    | 内置 5e 中文资料库（法术/怪物/物品/专长/背景/职业/状态/种族），支持查、筛、特性反查、跨库广搜 |
| **LLM 函数工具** | 9 个工具供 AI 主持人调用：掷骰/先攻/背包/商店/角色卡/车卡/构筑咨询/知识库/私设助手 |

## 安装

将本项目整个目录放入 AstrBot 插件目录 `data/plugins/` 下（目录名保持 `astrbot_plugin_trpg_assistant`），然后在管理面板启用「跑团助手」即可。

> **本项目是 [Dracowyn/astrbot_plugin_dnd_dice](https://github.com/Dracowyn/astrbot_plugin_dnd_dice) 的 fork**（MIT 协议，LICENSE 保留原作者版权声明），在原骰子插件基础上扩展为全能跑团助手。原插件骰池引擎、配置体系等核心代码均来自上游。

## 掷骰

### 命令

```
/r [表达式]       # 掷骰（无表达式时掷会话默认骰，初始 d20）；/roll 为别名
/dnd [组数]       # 按 5e 规则随机生成角色属性（每组掷 6 次 4d6kh3，默认 1 组，上限 20）
/dset [面数]      # 查询/设置会话默认骰面（如 /dset 6、/dset reset）；/dice_set 为别名
/rh [me|clear]    # 查看投掷历史（群聊显示全员，私聊仅本人）/ 只看自己 / 清空；/rhistory 为别名
/rprefix [符号]   # 查询/设置会话自定义触发前缀（如 .r 2d6、.dset 6），reset 恢复默认
```

- 表达式可带标签：`/r d20 攻击检定`、`/r d20#攻击检定`；DC 检定：`/r d20 感知 15` → 自动判定成功/失败。
- 历史为会话级、群聊私聊独立，最多保留 `max_history_count` 条（默认 50，展示最近 20 条）；解析失败的投掷不记录。`/rh clear` 在群聊需白名单权限。
- 自定义触发前缀是**额外**追加、不替换系统默认 `/` 前缀；设置后覆盖全部指令族（骰子/历史/先攻/背包/商店/知识库）。全局默认前缀由配置项 `default_cmd_prefix` 设置，会话级前缀优先于全局。
- 权限：`/dset`、`/rprefix` 受 `enable_whitelist`/`whitelist_users`/`allow_private_bypass_whitelist` 控制；**掷骰 `/r` 对所有人始终开放**。

### 骰池语法参考

> 各修饰符（`kh`/`kl`、`!`、`r`/`ro`、`s` 等）书写顺序不受限制，如 `4d6r<2kh3` 与 `4d6kh3r<2` 等价。

| 输入                        | 说明                         | 输出示例                                          |
| ------------------------- | -------------------------- | --------------------------------------------- |
| `/r d20`                  | 基础                         | `d20: [14] = 14`                              |
| `/r 1d20+5`               | 多骰组合                       | `d20+5: [9] +5 = 14`                          |
| `/r 2d6+1d4+3 伤害`         | 带标签                        | `伤害 2d6+1d4+3: [3, 5] [2] +3 = 13`            |
| `/r 4dF`                  | FATE/Fudge 骰               | `4dF: [+, 0, -, +] = 1`                       |
| `/r 4d6kh3`               | 保留最高 3（`k` = `kh` 简写）      | `4d6kh3: [(2), 4, 5, 6] = 15`                 |
| `/r 2d20kl1`              | 保留最低 1                     | `2d20kl1: [(18), 7] = 7`                      |
| `/r d20adv` / `/r d20dis` | 优势 / 劣势（2d20kh1 / 2d20kl1） | `2d20adv: [(8), 17] = 17`                     |
| `/r d20优势` / `/r d20劣势` | 中文优势/劣势（紧贴后缀，等价 adv/dis）     | `2d20adv: [(8), 17] = 17`                     |
| `/r 8d6d3`                | 丢弃最低 3（`dl`）               | `8d6dl3: [(1), (1), (2), 3, 4, 5, 5, 6] = 23` |
| `/r 8d6dh3`               | 丢弃最高 3                     | `8d6dh3: [1, 2, 3, 4, (5), (6), (6)] = 10`    |
| `/r d6!`                  | 标准爆炸骰（掷出 6 追加）             | `d6!: [6, 4!] = 10`                           |
| `/r d6!>4`                | 自定义爆炸阈值（≥4 即爆炸）            | `d6!>4: [5, 3!] = 8`                          |
| `/r 5d6!!`                | 复合爆炸骰（追加值合并为单骰）            | `5d6!!: [2, 3, 5, 8, 14] = 32`                |
| `/r 5d6!p`                | 穿透爆炸骰（可连锁，追加骰 -1 可为 0）     | `5d6!p: [3, 5, 2, 6, 1, 1!] = 18`             |
| `/r 3d6>3`                | 成功计数（≥3 算成功，`*` 标注）        | `3d6>3: [1, 4*, 5*] = 2成功`                    |
| `/r 3d6>3f1`              | 失败计数（=1 算失败，`x` 标注）        | `3d6>3f1: [4*, 1x, 6*] = 2成功 1失败`             |
| `/r 2d8r<2`               | 循环重掷（`~N~` 标注被替换值）         | `2d8r<2: [~1~, 7, 5] → [7, 5]`                |
| `/r 2d6ro<2`              | 单次重掷（每骰最多一次）               | `2d6ro<2: [~1~, 4, 6] → [4, 6]`               |
| `/r 8d6s` / `/r 8d6sd`    | 升序 / 降序显示                  | `8d6s: [1, 2, 2, 3, 4, 5, 6, 6] = 29`         |
| `/r 3#d20+d6`             | 重复投掷 3 次（上限 20）            | `3#d20+d6: 重复 3 次` + 逐行 `#N` + 合计/平均      |
| `/r 3d6*(2+4)d12`         | 四则运算 + 括号                  | `3d6*(2+4)d12: [3, 5, 4] * [4, 6, ...] = 288` |
| `/r (2+3)d6`              | 括号算式作骰数                   | `(2+3)d6: [4, 3, 1, 1, 1] = 10`               |
| `/r 3d(2*4)`              | 括号算式作骰面                   | `3d(2*4): [8] = 8`                            |
| `/r d20 感知 15`            | DC 检定（标签与数字间须有空格）          | `感知 d20: [12] = 12 / 15 失败`                   |

限制与规则：

- 优势/劣势固定 2 颗骰子，显式骰数 >2（如 `3d20adv`）会报错。
- 中文「优势/劣势」**必须紧贴骰子**（`d20优势`、`d20优势+2`、`d20优势+1d4`）；带空格（`d20 优势`）、前置（`优势d20`）或单独使用会报语法错误，避免「以为是优势实际没加」的静默失误。
- 多重投掷 `N#` 仅当 `#` 左侧整体为纯数字且位于表达式开头时生效（`d20+5#攻击` 的 `#` 仍是标签分隔符）；重复次数上限 `max_repeat_count`（默认 20），且重复投掷**不支持 DC 与大成功/大失败判定**。
- 四则运算优先级乘除高于加减，除法向下取整（`3d6/2` 取整）；括号可嵌套、括号内可含骰子（`(2d6+1)d8`）；带 `>N`/`<N`/`fN` 计数修饰的骰组不能参与四则或括号（`3d6>3+2` 报错）。
- `/dnd [组数]` 结果不会自动写入角色卡（走 `/车卡` 的掷骰开卡才会落草稿），仅作生成与分配参考。
- 自定义爆炸条件若对该骰型所有面值恒成立（如 `d6!>1`）会被拒绝，避免爆炸链无法终止。
- DC 检定：总计 ≥ DC 成功，< DC 失败；天然 20 大成功、天然 1 大失败（仅单组 d20 表达式生效）。

## 先攻追踪

按 DnD 5e 规则管理战斗先攻。玩家有活跃角色卡时，`/ri` 无参数自动使用卡上先攻（= 敏捷修正 + 房规加值，如警觉专长 +5 用 `/卡 设 先攻 5` 追加），并标注来源角色；显式给调整值时以显式值为准。

```
/ri               # 掷 d20 先攻入列（有活跃卡时自动带卡上先攻）
/ri +3            # 掷 d20+3 先攻入列（本人）
/ri +2 食人魔     # 为具名单位代掷 d20+2 入列（DM 代掷）
/ri 15 哥布林甲   # 以固定值 15 录入（DM 抄书值）
/init             # 查看先攻列表（降序，▶ 标记当前行动者，显示轮数）；/initiative 为别名
/init end         # 推进回合：播报上一位结束、下一位行动；绕回列表顶部时轮数 +1
/init del 名称    # 移除单位（倒下/离场），移除当前行动者时指针自动接力
/init clr         # 清空本场战斗
```

- 先攻值降序排列，同值时先入列者先行动。
- 列表按会话（群聊/私聊）隔离，KV 持久化、不自动过期，跨周续团不丢状态。
- `/init del` 与 `/init clr` 为破坏性指令，群聊需白名单/管理员权限；其余指令全员开放。

## 跑团记录

记录一场跑团活动的**完整对话流**（玩家消息 + 机器人回复，含 LLM 扮演 DM
的旁白），并把记录提取为**叙事式战报摘要**。数据存独立 SQLite
（`data_dir/trpg_log.db`，升级插件不丢）。

### 团 / 场次

- **团** = 一个命名的记录容器，按会话隔离：`/开始记录 <团名>` 存在则续写、
  不存在则新建（同一会话同一时间只能记录一个团）；
- **场次** = 团内一次「开始 → 结束」的区间，团内第 N 次开团即第 N 场；
  摘要默认最近一场，可指定场次。

```
/开始记录 红龙之影    # 新建团「红龙之影」并开始记录第 1 场
/暂停记录             # 暂停：之后消息不入日志，场次保留（中场休息用）
/继续记录             # 恢复已暂停的场次
/结束记录             # 结束当前场次，数据保留
/记录                 # 查看当前记录状态与团列表
/记录 看 红龙之影     # 查看日志原文（最近 20 条，[结算] 标记骰指令）
/记录 摘要 红龙之影   # 查看已生成的场次摘要
/总结 红龙之影        # 生成叙事式战报摘要（剧情回顾 + 结算统计）
/总结 红龙之影 2 重算  # 指定第 2 场并强制重新生成（忽略缓存）
/删除记录 红龙之影    # 删除整个团（不可恢复）
/导入记录 红龙之影    # 导入既有纯文本记录为团的新场次（粘贴文本，或上传 .txt/.log 文件）
```

- **导入旧记录**：把已经开过一段时间的团的记录倒灌进来——命令后直接粘贴文本
  （每行一条，支持 `昵称: 内容` / `[时间] 昵称: 内容`），或上传 .txt/.log 文件
  （utf-8/gbk 自动识别）；按行规则切分、骰式行预标结算，落为团的一个新场次，
  随后 `/总结 <团名>` 即可生成摘要。写操作需权限。
- **摘要**：规则预标「结算」（玩家骰指令写入时确定性打标）+ LLM 分类
  （行动 vs 吐槽）并写成叙事回顾；结算折成结果（如「攻击命中，造成 12
  伤害」）、吐槽剔除、末尾附结算统计；结果落库可回看，不重复烧 token。
- **权限**：开始/暂停/继续/结束/删除/导入为写操作，群聊需白名单/管理员
  （私聊放行）；查看与摘要全员可用。
- 记录过长时摘要取最近窗口并注明；`/帮助 记录` 查看命令语法。

## 背包与商店

### 背包（Inventory）

「个人背包 + 队伍背包」双模型：个人背包归属单个玩家（会话隔离），队伍背包归属整个群聊、全员共享。

**指令别名**：`/背包`、`/inventory` 与 `/bag` 完全等价，任选其一（自定义前缀下 `.背包` 同样可用）。

```
/bag                                # 查看自己的背包（含总重量/总价值统计）
/bag list @某人                     # 查看他人背包（只读）
/bag add 治疗药水 3                  # 放入 3 个治疗药水
/bag add 治疗药水 3 w=0.5 v=50 note=群体治疗   # 带单件重量/价值/备注
/bag add "精灵 斗篷" 1               # 名称含空格用英文双引号
/bag rm 治疗药水 2                   # 取出 2 个（数量缺省 1，归零自动删除条目）
/bag edit 治疗药水 w=0.8             # 修改重量（只改提供的字段；w=- 表示清除）
/bag give @某人 治疗药水 1           # 赠送给其他玩家
/bag party                          # 查看队伍背包
/bag put 金币 50 / /bag take 治疗药水  # 存入 / 取出队伍背包
/bag clear / /bag party clear        # 清空个人 / 队伍背包（后者需白名单权限）
/发放 治疗药水 3 价=5银 火球术卷轴 1  # DM 向队伍背包批量发放战利品（全员可用，可带 重=/价=/备注=）
/收回 火球术卷轴 1                   # DM 批量撤回发错的物品（管理员/白名单）
```

规则细节：

- **物品模型**：名称 + 数量（必填）+ 可选单件重量（`w=`）、价值（`v=`）、备注（`note=`）。重复放入同名物品数量累加，本次提供属性则覆盖旧属性。
- **批量操作**：`/发放`、`/bag add/rm/put/take` 均可一条指令多件（`/bag add 治疗药水 2 绳索 1`），逐件原子、失败列明、成功 N 件/失败 M 件汇总；`/发放` 支持 `重=X`/`价=X`（支持 2金5银 写法）/`备注=X` 逐项属性归属。纯文本输出，无 `**` 等不解析的 Markdown 符号（ADR-0017）。
- **货币即物品**：金币/银币/铜币就是普通物品条目，无独立钱包；价值统一为**铜币口径**（1金=10银=100铜），显示换算为「X金Y银Z铜」，背包总价值=折铜后的财富总额。
- **只统计不限制**：背包显示总重量/总价值，存在未设重量/价值的物品时总计追加 `+`（「至少」）；是否超载由 DM 裁定。
- **流转原子性**：`put`/`take`/`give` 要么完整生效，要么两侧均不变（数量不足时）。

### 商店系统（Shop）

**会话商店**（`/商店`）：DM 配置商品列表，玩家自助买卖，插件自动结算货币。一个会话一家店，价格默认取知识库库价（PHB 定价），DM 可为单个商品覆盖价格。

```
/商店                              # 查看商品列表（覆盖价优先，否则显示库价，每页 30 条；/商店 2 翻页）
/商店 买 长剑 1                    # 购买：自动扣背包货币并找零（1金=100铜）
/商店 卖 皮甲 1                    # 卖回：只收在架商品，按售价×回购系数付款
/商店 买 长剑 匕首 2               # 批量购买：长剑×1 + 匕首×2（数量省略=1）
/商店 卖 皮甲 盾牌                  # 批量卖回：皮甲×1 + 盾牌×1
/商店 初始化                       # 一键上架 PHB/XPHB 非魔法物品（管理员）
/商店 上架 神秘符咒 价=3金 库存=2  # 上架（价/库存可选，不写价则用库价；管理员）
/商店 上架 长剑 价=2金 匕首 库存=3 # 批量上架：逐项属性归属（管理员）
/商店 下架 神秘符咒 / /商店 下架 长剑 匕首   # 下架（可批量；管理员）
/商店 设价 长剑 2金 / /商店 设库存 长剑 5
/商店 回购率 0.5                   # 回购系数（卖出价=售价×系数，clamp 0–2；管理员）
/商店 清空                         # 清空整店全部商品（管理员；回购系数保留）
```

- **批量操作**（v0.39.0）：买/卖支持「名称 [数量]」交替、数量省略=1（数字 token 归属前一物品）；上架支持逐项属性（`价=`/`库存=` 归当前物品）；批量逐件结算——某项失败（不在架/库存不足/钱不够）不影响其他项，结果逐行列出。LLM 函数工具 `manage_shop` 同步支持批量（`items` 数组参数）。
- **初始商店**：`/商店 初始化` 从知识库取 PHB/XPHB 非魔法物品全量上架（同名多版本去重、取 2024/XPHB 价，共 246 种），默认库价、无限库存；会覆盖现有商品但保留回购系数。
- **购买自动同步**：成交入包的物品自动带上知识库的重量与价值（铜币），实现「物品库 → 背包」同步；买错可 `卖` 回。
- **结算规则**：货币只认 金币/银币/铜币 三条目（面值 100/10/1 铜币），折铜扣款、自动找零（整币优先、最多破开一枚大币）；钱不够/售罄/非在架时整体不写入（原子）。
- **权限**：上架/下架/设价/设库存/初始化/回购率/清空为管理操作（群聊需白名单/管理员，私聊放行）；买卖与查看全员开放。LLM 工具中的管理动作同样鉴权（v0.39.0 起）。
- **限制（v1 明确不做）**：多店/分店、魔法物品自动上架、交易税、2024 起始财富自动发放。

## 角色卡与车卡引导

### 角色卡（`/卡`）

一个玩家（会话内）可有多张命名卡，一张为活跃卡。支持活跃切换、改名、删除、设置字段、增减熟练、命名掷骰。

```
/卡                                  # 查看活跃角色卡（摘要卡；全文走 /卡 详情）
/卡 列表 / /卡 用 二号卡 / /卡 删 <卡名> / /卡 改名 <旧名> <新名>
/卡 设 hp 25                         # 设置字段（bonus 层，手动调整）
/卡 设 力量 18 / /卡 设 敏捷 99       # 六维属性单独设置（clamp 1-30，自动联动重算；99→30）
/卡 设 种族 半精灵                   # 种族（短文本）；/卡 设 版本 2024（或 5.5e）切规则版本
/卡 设 职业 战士 3 + 法师（塑能） 2  # 职业整体替换（含子职与等级，- 清空），自动重算
/卡 设 主手 长剑                     # 装备槽（- 清除）；/卡 设 攻击 长剑=6 命名攻击加值
/卡 设 背景 侍僧 / /卡 设 生平 <长文本>  # 「背景故事」同为生平别名
/卡 设 语言 通用语,精灵语 龙语        # 多门语言（逗号/空格分隔，整体覆盖）
/卡 设 性别 女                        # 人物信息：信仰/年龄/性别/身高/体重
/卡 设 激励 1                         # 资源：激励、生命骰已用
/卡 设 先攻 1                         # 先攻房规额外加值（base=敏捷修正自动算）
/卡 设 法术 戏法:火焰箭,光亮术　1环:护盾术  # 已知法术（环阶:法术名，组间全角空格/分号分隔）
/卡 详情 [字段]                       # 完整字段：背景/生平/人物信息/专长/特性/攻击/熟练/语言/装备/法术/掷骰
/卡 熟练 技能 +察觉 -隐匿             # 增减技能熟练；豁免/工具/武器/防具同理
/卡 专精 +察觉 -隐匿                  # 技能专精：该技能检定双倍熟练（卡上带 ★）
/卡 专长 +巨武器大师 -幸运            # 维护专长列表（保存时提示知识库是否收录）
/卡 法术 加 一环 护盾术 / /卡 法术 删 1环 护盾术  # 已知法术单条增删
/卡 升级 [职业名] / /卡 降级 [职业名]   # 职业 ±1 级（默认主职业，最低 1 级），战斗字段自动重算
/卡 骰 侦察 1d20+2                   # 命名掷骰（登记后 /r 侦察 直接用该表达式；- 删除）
/卡 导入 <卡文本>                     # 文本角色卡解析落库（多行可换行粘贴，战斗字段自动重算）
```

**掷骰联动**：`/r 力量`、`/r 察觉`、`/r 敏捷豁免` 自动查活跃卡拼 `1d20+修正` 并注明来源；没有活跃卡时回退为普通报错。**命名掷骰**：`/卡 骰 <名称> <表达式>` 登记后 `/r <名称>` 直接用该表达式；与内建别名冲突时命名掷骰优先（玩家显式意图）。

**攻击检定**：`/r 攻击` 用卡上攻击加值掷 `1d20+加值`——无参数默认主手武器；`/r 攻击 <武器名>` 按名字匹配（精确→前缀→包含，尾数纯数字视为 DC，如 `/r 攻击 长弓 15`）；`/r 攻击 列表` 枚举全部攻击选项（武器 + 「{职业}法术攻击」+ 手动条目）；主手为空/未知名/无条目时给出友好提示（提示类输出不写入历史）。

**进阶熟练规则**：

- **技能专精**：`skill_expertise` 独立于技能熟练存储（旧数据零迁移），专精检定双倍熟练加值；对未熟练技能加专精会提示但不阻断。
- **吟游诗人万事通**：卡上有「吟游诗人」≥2 级自动生效——纯属性检定与未熟练技能检定获得 ⌊熟练加值/2⌋；豁免与已熟练技能不受影响；被动感知自动联动。升级/兼职由等级动态判定。
- **武器熟练影响攻击**：按内置 PHB/XPHB 简易/军用武器中文词表判定装备武器是否熟练，不熟练时不加熟练加值并提示；**魔法武器自动解析基础武器**（知识库 base_item：雷神之锤→巨锤、+1 巨锤→巨锤），词表外武器与未维护武器熟练的旧卡回退为熟练（细则交 DM）。

### LLM 引导车卡（`/车卡`）

由 LLM 按 DnD 规则逐步提问引导创建角色（**一次只问一个问题**，可查知识库答疑）。插件维护引导状态机（草稿可跨重启续传），属性生成与校验全部由插件确定性执行：

- **2014 路径**：确认规则 → 种族 → 职业 → 背景 → 属性 → 阵营 → 生平 → 命名
- **2024 路径**：确认规则 → 职业 → 起源（背景+物种）→ 属性 → 阵营 → 生平 → 命名
- 生平环节按 XGE「这是你的人生」结构（出身 → 个人决定 → 人生经历）引导，纯文本记录
- 完成落库后自动成为活跃卡；**2014 职业自动代骰发放起始金币**（如 5d4×10 金币，写入个人背包），2024 职业的起始财富含在装备方案（A/B/C）里由 LLM 引导玩家选择、不自动发放

```
/车卡           # 开始/继续引导（LLM 逐步提问，一次一问）
/车卡 状态      # 查看引导进度与当前问题
/车卡 答 <答案>  # 提交当前步答案（无 LLM 时兜底）
/车卡 导入 <卡文本>  # 文本角色卡落库兜底
/车卡 取消      # 中止引导并丢弃草稿
```

### 群开卡规则（`/车卡规则`）

DM/管理员设置群级开卡规则（写入需群聊白名单权限）：

```

/车卡规则 属性 购点 池=32 上限=17     # 自定义购点（池/下限/上限）
/车卡规则 属性 掷骰 5d6kh3 6         # 自定义骰式
/车卡规则 子职时机 开|关|按规则       # 开卡即选 / 不选 / 按规则等级
/车卡规则 起始等级 3
/车卡规则 起始金币 自动|150|5d4×10    # 按职业代骰 / 全团固定 / DM 自定义骰式
```

- **起始金币**：车卡落库时按群规则发放（单位=金币）。`自动`=按职业 goldAlternative 代骰（2014 职业）；纯数字=固定金额；骰式=DM 自定义随机财富。2024 职业不自动发放（见上）。
- 校验**硬拒绝**：购点超池、属性出区间、骰池多重集不符、标准数组不符 → 拒绝保存并提示「请 DM 用 /车卡规则 调整」；种族/背景属性加值在「加值选择」步列出方案并硬校验，落库时自动叠加。

### 战斗字段双层模型

- **base 层**：由规则引擎自动计算——HP（首职首级满骰+期望值+体修）、法术位（full/half/third/artificer/pact+兼职施法合并）、AC（护甲/盾/无甲防御取高）、攻击加值（装备槽武器+各施法职业法术攻击）；任意等级 1-20、兼职、升级整卡重算。
- **bonus 层**：房规调整，`/卡 设 hp/ac/法术位N/攻击` 仍写 bonus，任何自动重算都不覆盖。
- 已知限制：PHB 人类（2014）+1 全属性在数据源无结构化字段，不自动叠加；邪术师在数据源中名为「魔契师」。
- 存储按会话与玩家隔离，KV 持久化、不自动过期；`/bag party clear` 为破坏性指令需白名单权限（私聊无队伍背包）。

### 特性

- **同名多版本**：2014/2024 两版并存时全部列出并标注来源（如 `[PHB·2014]`、`[XPHB·2024]`）；物品的 `reprintedAs` 旧版条目自动重定向到再版条目。
- **模糊搜索**：中英文名、别名精确命中 → 名称包含 → 逐字缩短三级容错；多候选时列编号供指名。
- **富化反查**：专长（276 条）/职业（29 条）/子职（186 条）/种族（160 条）/背景（148 条）均带 AI 生成的一句话概要、定位与能力关键字（如 `/查职业` 头部展示「定位：武者」「概要：…」），支持类型/属性提升/先决条件/能力标签等多维反查；法术支持职业法术表反查（按职业可施展的法术列表）。
- **跨库广搜**：`/查询` 一次搜索全部条目类别并按类别分组，`-全文` 参数启用正文搜索。
- **机翻标注**：凡未标注人工译者（不全书）的条目标记 `⚠️机翻`，请 DM 自行甄别。
- **数据补丁**：5e.tools 上游未收录的官方物品（如「警戒武器」）通过 `kb_patches/` 补丁通道合并入库，构建时自动加载（抓取脚本 `scripts/fetch_chm_patch.py`，数据源 5E 不全书 CHM 站）。
- **零幻觉**：LLM 工具返回固定附带「仅可依据原文作答」约束；`/查X` 命令直出原文、不经 LLM。
- **更新方式**：数据随插件版本打包，更新知识库 = 安装新版插件 zip；旧版 `kb_update.db` 会因 schema 版本过低自动回退到内置库。

### 私设（房规）数据

内置知识库只读；想加自己的房规（法术/怪物/物品/专长/背景/种族/职业…）时，把 JSON 文件放进 AstrBot 数据目录下的 `trpg_homebrew/` 文件夹（没有就新建），执行 `/kb reload` 热重载即可，**不用重启**、不用改代码。

```
/kb reload    # 重载私设目录（加/改文件后执行）
/kb 私设      # 查看当前私设概况（文件数/条目数/覆盖数）
```

- **文件格式**（二选一，可混用）：**5etools 标准格式**（顶层键 = 条目类型 `spell`/`monster`/`item`/`feat`/`background`/`condition`/`race`/`class`/`subclass`，值 = 条目数组，正文走 `entries`/`trait`/`action` 等字段）；**简化格式**（条目内直接写 `kind`（中文如「法术」）/`name`/`source`/`body` 纯文本，最易上手）。
- **来源码与覆盖**：`source` 建议用独立代号（如 `DM`/`MYHOUSE`）。与官方 `(类型, 名称, 来源)` 完全相同即为**覆盖**——查询时房规版本置顶并标注 `🏠房规`；来源独立则纯新增。想「改掉」某个官方条目，就用与官方相同的来源码覆盖。
- **标签反查（可选）**：条目可带 `tags` 字段（`{"facet": ["值1"]}`）参与 `/筛X` 反查，facet 用官方词表（如法术 `spell_keyword`/`dmg_dealt`、物品 `weapon_property`/`item_type`、职业 `class_role`/`class_keyword` 等）。
- **示例**：插件包内 `homebrew_examples/` 目录有 4 个可直接复制的示例文件（法术/物品/怪物/职业各一，两种格式都有）。
- **边界**：私设职业/子职只支持名称查询与正文展示，不参与规则引擎联动；简化格式缺结构化字段时对应维度（环级/CR/稀有度）筛选不命中，但名称查询与全文展示不受影响。

**私设助手（v0.37.0，LLM 工具 manage_homebrew）**：不想手写 JSON 时，直接把纯文本房规发给 AI 主持人即可——助手会转录为合法私设 JSON 并经插件权威校验（双程校验）后贴回；也可以让它点评私设的平衡性（点评前会被强制要求先查官方同类条目对照，禁止仅凭记忆）。想让助手**直接写入** `trpg_homebrew/`：在插件配置开启 `homebrew_write_enabled`（默认关），且操作者需为白名单用户或管理员（私聊同样受限）；目标文件已存在时助手会先列出存量条目请你确认，再按你的选择整文件替换或按条目合并，写入后自动热重载生效。

已知限制：职业-法术关联（某职业能学哪些法术）因上游中文数据未携带 `classes` 字段暂不提供；法术的「范围形状 / 目标」按描述文本启发式提取（宁缺毋滥、不标注），可能有遗漏；施放型物品（如法杖）造成的伤害需文本包含「X伤害」字样才会被标记；法杖（staff）类物品在源数据中无独立 type 编码，未单列为物品大类。

## LLM 函数工具

插件注册十个工具，启用 Agent 模式后，LLM 可在 TRPG 叙事中主动调用。

> **⚠️ AI 主持人配置建议**：**不要**给 AI 主持人的 LLM 环境挂载代码执行/文件访问类能力（MCP 代码执行器、文件系统工具等）。本插件的所有数据（知识库/商店/背包）都有专用工具作为权威接口；让 LLM 直接读插件目录里的 `dnd_kb.db` 等文件会拿到无格式保证的内部数据。若无法移除这些能力，请在 AI 系统提示词中明确：「查询 D&D 数据必须调用 query_dnd_knowledge 工具，禁止读取本地文件」。
> 
> **工具触发引导**：插件通过 `@filter.on_llm_request` 钩子向每个 LLM 请求的 system prompt 注入压缩版「跑团助手·工具守则」——全部 10 个工具按场景一句一条（掷骰→`roll_dice`、规则数据→`query_dnd_knowledge`、战斗→`manage_initiative`、战利品→`manage_inventory`、角色卡→`manage_character`、车卡→`guide_chargen`、买卖→`manage_shop`、构筑→`advise_build`、私设→`manage_homebrew`、记录/战报→`summarize_session`），并明确**破坏性操作不主动执行**、等玩家明确要求。这是防 LLM「扮演/编造而不调工具」的双保险，无需 WebUI 额外配置。
> 
> **部署提示**：AstrBot v4.5+ 需在 WebUI 工具管理面板**启用**插件工具（默认不注入 LLM 请求），否则 AI 主持人看不到工具。

| 工具                    | 触发场景                       | 关键参数（action）                                                                                                                                                                |
| --------------------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `roll_dice`           | 攻击/伤害骰、属性检定                | `expression`（骰池，可省略掷默认骰）、`label`、`dc`                                                                                                                                       |
| `manage_initiative`   | 战斗开始掷先攻、推进回合、单位倒下          | `roll`/`fixed`/`list`/`end`/`remove`/`clear` + `name`/`value`/`modifier`                                                                                                    |
| `manage_inventory`    | 战利品/消耗/查看物资/队伍转移           | `add`/`remove`/`list`/`put`/`take`/`edit`/`clear` + `item`/`qty`/`weight`/`value`/`note`/`to_party`                                                                         |
| `manage_shop`         | 购买商品、卖回商店、查看商品、DM 上架/下架/清空 | `list`/`buy`/`sell`/`add`/`remove`/`clear` + `item`/`qty`/`items`（v0.39.0 起批量 `items` 数组；add/remove/clear 为管理动作，工具内鉴权）                                       |
| `manage_character`    | 查看/切换/删除/改名卡、设字段、增减熟练、命名掷骰 | `show`/`list`/`use`/`delete`/`rename`/`set`/`prof`/`named_roll` + `name`/`field`/`value`/`new_name`                                                                         |
| `guide_chargen`       | 引导新手车卡（工具返回驱动）             | `start`/`answer`/`status`/`cancel` + `answer`/`assign`/`race`/`class_name`/`background`（一次只问一个问题、禁止替玩家作答）                                                                   |
| `advise_build`        | 构筑咨询/升级建议                  | `new_build`/`level_up` + `goal`/`keywords`/`level`；推荐条目全部来自知识库反查、禁止凭记忆编造                                                                                                    |
| `query_dnd_knowledge` | 查法术/怪物/物品效果、职业能力、条件筛选      | `detail`/`search`/`filter`/`class_features`/`version` + 40 个筛选参数（`kind`/`name`/`level`/`school`/`cr_min`/`rarity`/`damage_type`/`condition`/`spell_class`/`feat_keywords`…） |
| `manage_homebrew`     | 私设转录/写入/点评                  | `convert`/`write`/`review` + `json_text`/`filename`/`overwrite`/`merge`；write 需配置 `homebrew_write_enabled` + 白名单/管理员（私聊不放行），点评前必须先查库对照 |
| `summarize_session`   | 跑团记录/战报摘要/团状态              | `summarize`/`status`/`view`/`start`/`pause`/`stop`/`delete` + `campaign`/`session_seq`/`force`；摘要缓存可回看、`force` 重算；写操作需玩家明确要求且插件内校验权限 |

工具返回固定附带「仅可依据其作答、未提及不要编造」约束；查无结果时明确返回「未找到」而非空串。

## 与 Roll20 规范的差距

以下功能在 [Roll20 骰子规范](https://help.roll20.net/hc/en-us/articles/360037773133-Dice-Reference) 中明确定义，但当前版本**尚未实现**：

| 未实现功能            | 规范语法示例                                    | 说明                         |
| ---------------- | ----------------------------------------- | -------------------------- |
| 数学函数             | `floor(2d6/2)`、`ceil()`、`round()`、`abs()` | 完全未实现（已支持 `+ - * /` 四则与括号、整除向下取整） |
| 取模/幂             | `d20%2`、`2**3`                             | 已支持四则与括号，但 `%`/`**` 未实现          |
| 分组骰              | `{3d6+5, 2d8+4}kh1`                       | 花括号跨骰池保留/丢弃                |
| 自定义临界点 `cs`/`cf` | `1d20cs>18`、`1d20cf<3`                    | 天然 20/1 硬编码于 d20，无法自定义临界范围 |
| 每组独立内联标签         | `2d6[Fire]+3d8[Ice]`                      | 仅支持全局单一标签                  |
| 骰子匹配 `m`/`mt`    | `6d6mt3`、`6d6mt3>4`                       | 配对数/配对计数修饰符                |

## 路线图

1. **重复掷骰（已实现 `N#`）**：`3#1d20+5` 已支持（v0.47.0）；`6x4d6kh3`（`x` 车卡属性生成写法）待做。
2. **暗骰**：投掷结果仅私发给投掷者或 GM，群内只提示已投掷。
3. **CoC 模式**：d100 奖励/惩罚骰、成功等级、SAN check。
4. **投掷统计**：`/rstats` 基于历史输出均值、大成功/大失败次数。
5. **自定义掷骰表**：`/table` 管理随机表，大成功/大失败自动触发抽取。
6. **表达式增强**：括号与四则运算已实现（v0.47.0）；Roll20 分组骰、数学函数仍待做。
7. **背包物品模型升级**：道具信息从备注升级为结构化字段，支持装备槽位、掷骰自动消耗（如弹药）、可选负重判定（KV 结构已预留向后兼容路径）。

## 数据与许可

知识库数据（`kb_data/dnd_kb.db`）源自 [5etools 中文站](https://github.com/tjliqy/5etools-mirror-2.github.io)（`tjliqy/5etools-mirror-2.github.io`，cn2.0 分支）`data/` 目录下的中文本地化 JSON，许可为 **CC BY-NC-SA 4.0**：

- **署名（BY）**：译文版权归原译者（不全书等）与「DND 共库」整理者所有，本插件在 `NOTICE` 与 `/kb version` 中署名；
- **非商业（NC）**：本插件仅限非商业使用；
- **相同方式共享（SA）**：本插件派生的知识库数据库以相同许可发布。

插件代码本体（不含知识库数据）沿用上游 MIT 许可。数据文件在构建时经离线清洗（5etools 内联标签 → 纯文本）编译为只读 SQLite，构建脚本见 `scripts/build_kb.py`。
