# 开卡规则为群级配置，校验硬拒绝（DM 改规则是唯一特许路径）

开卡规则（版本 2014|2024、属性生成方式、子职时机、起始等级）是**群级**
配置，存 `chargen_rule:{origin}`，仅 DM/管理员（`_check_destructive_permission`）
可写，全团玩家车卡时统一遵守。属性生成方式为参数化模板（购点法：点数池
+区间；掷骰法：骰式+次数；标准数组），内置别名注册表 27buy/32buy/dnd5/
标准数组可扩展。

校验**硬拒绝**：购点超池/属性出区间/骰池多重集不符/标准数组不符 → 拒绝
保存且状态不推进，错误文案指向「请 DM 用 /车卡规则 修改群规则」。

## Considered Options

- **校验警告但放行**：与背包「只统计不限制，DM 裁定」的既有惯例一致，
  但车卡场景中超支/超限多半是**填错了**而非 DM 特许；放行会把错误固化
  进角色卡，新手也分不清「警告」与「禁止」，否决。
- **玩家自选规则**：实现简单，但「DM 说 27buy 玩家偷偷 dnd5」时校验
  形同虚设，引导话术也不知道听谁的，否决。
- **静默 clamp（超限自动截断）**：最省事，但掩盖错误且与房规特许无法
  区分，否决。

## Consequences

- 特许路径唯一且明确：改群规则。DM 一次性特许（如「给你 +2 点开挂」）
  有两种落地方式：改群规则，或 v0.17 起在卡片上手动调整（见战斗字段
  双层模型，bonus 层），两者不冲突。
- 无规则 KV 时返回默认规则（2014 + 27buy + 子职按规则 + 1 级），
  保证任何会话开卡都有确定口径。
- 规则写入走破坏性权限检查：私聊任何人可改（仅影响自身会话），群聊
  需白名单/管理员。
