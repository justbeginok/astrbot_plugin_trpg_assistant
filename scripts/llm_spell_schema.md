# LLM 法术富化契约（spell enrich，v2 标签体系）

日期：2026-08-18（v0.53.0 法术标签/概要重做）
参照：`llm_monster_schema.md`（monster_extract 契约模式）、`llm_class_schema.md`（class_extract 契约模式）。

## 背景

v0.53.0 起法术标签体系从「AI 自由词」收敛为 **13 个效果域大类**；概要统一为
「≤30 字、含效果+目标+代价」的一句话。本契约定义 LLM 为每个法术生成
`summary + keywords` 的输出格式与硬约束，保证 1220 条口径一致、零词表外。

## 输入

给定一条法术的结构化记录（来自 `scripts/_md_cache/spells_chm.json`）：

```json
{
  "name": "火球术",
  "eng_name": "Fireball",
  "source": "XPHB",
  "edition": "2024",
  "level": 3,
  "school": "塑能",
  "time": "动作",
  "detail_range": "150尺",
  "detail_duration": "立即",
  "detail": "明亮的闪光从你的指间飞驰向施法距离内你指定的一点，并随着一声低吼迸成一片烈焰。目标点周围半径20尺球状区域内的每个生物必须进行一次敏捷豁免。豁免失败者将受到8d6点火焰伤害，豁免成功则伤害减半。\n\n区域内所有未被着装或携带的可燃物件会开始燃烧。",
  "detail_higher": "升环施法。使用的法术位每比三环高一环，此伤害就增加1d6。"
}
```

## 输出

输出一个 JSON 对象（仅 JSON，无其他文字），结构：

```json
{
  "name": "火球术",
  "source": "XPHB",
  "edition": "2024",
  "summary": "向指定点掷出爆裂火球，20尺半径内生物敏捷豁免失败受8d6火焰伤害。",
  "keywords": ["伤害"]
}
```

## 硬约束

1. **keywords 只能从下面 13 类中选**，1–3 个，按重要度排序；禁止词表外词
   （如 火焰/寒冷/球状/亡灵/变身/元素 等一律不得出现，它们由结构化 facet
   承接）：

   `伤害 / 治疗 / 增益 / 控场 / 位移 / 防护 / 召唤 / 侦查 / 潜行 / 社交 / 探索 / 幻术 / 即死`

2. **summary 硬格式**：
   - ≤ 30 个汉字（超出即不合格）；
   - 必须包含三要素：**效果**（做什么）+ **目标**（对谁/范围）+ **代价**
     （豁免/攻击检定/伤害数值等，可省略时用「需X豁免」类短语）；
   - 陈述句、不用「该法术/此法术」开头、不用引号。

3. 分类参考（判定口径，与构建期规则一致）。总原则：**按效果的实质目的分类，
   而非按目标是谁**——提升我方输出/生存（含给敌人的输出 debuff）→ 增益；
   限制敌人行动 → 控场；造成伤害（含持续掉血）→ 伤害。
   - **伤害**：正文含「X点Y伤害/受到伤害/造成伤害」，以及持续伤害（dot）
     状态——如每回合结束受伤害的灼烧/中毒/酸蚀等；
   - **治疗**：恢复生命/临时生命/复活；
   - **增益**：给己方加值/护甲/优势/抗性/免疫/加速；以及削弱敌人的输出类
     debuff（敌人攻击劣势、受伤害增加、伤害骰取最大等）——本质是提升我方
     输出/生存，归增益而非控场；
   - **控场**：限制敌人行动的状态（束缚/定身/麻痹/震慑/昏迷/目盲/耳聋/失能/
     恐慌/石化/减速/受擒），或铺场地限制移动的效果；**不含纯输出 debuff**
     （归增益）、**不含持续伤害状态**（归伤害）；
   - **位移**：传送/瞬移/闪现/击退/强制移动（含自己移动）；
   - **防护**：护盾/结界/庇护/减伤/吸收伤害/屏障；
   - **召唤**：召唤生物/仆从/造物（创造物品、食物也归此）；
   - **侦查**：侦测/探知/识破隐形/占卜/预言；
   - **潜行**：隐形/隐匿/无声行动；
   - **社交**：说服/魅惑人/读心/谎言/语言；
   - **探索**：飞行/游泳/呼吸/攀爬/开锁/环境适应/传送门；
   - **幻术**：幻影/幻象/幻觉/虚假影像；
   - **即死**：直接消灭/秒杀/生命值归零即死；
   - 「战斗辅助/施法辅助」已并入**增益**；「造物」已并入**召唤**；
     「减益」拆分：限制行动类并入**控场**，削弱输出类并入**增益**。

4. 拿不准时宁缺毋滥：一个法术最多 3 个标签，只给有把握的；纯效用/环境类
   法术（如照明、清洁）可不给任何标签，但 summary 必须给。

5. name/source/edition 原样回填，不得改写。
